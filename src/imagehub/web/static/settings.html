Настройки

Принудительно запускает локальные модели на процессоре и использует отдельный локальный сервер Ollama с отключёнными GPU и облаком. Это может существенно замедлить обработку. Выбранный режим сохраняется после перезапуска.

Переключение доступно между волнами обработки. Текущий отдельный эксперимент не меняется.
