# Соответствие постановке

Проверка исходного кода, 10 ноября 2026 г. «Частично» означает, что сценарий или близкий механизм присутствует, но указанное требование буквально не выполнено либо отсутствует подтверждение реальным прогоном.

| Критерий | Результат | Основание |
|---|---|---|
| Описание, вопросы, OCR, обработка папки, поиск | Выполнено с оговорками | Сценарии реализованы и проверены на реальных моделях; оценка качества датасетов выполнена на небольших выборках, а не на полных наборах. |
| SmolVLM-500M / Moondream2; Ollama qwen2.5vl:3b / moondream | Другая конфигурация | Qwen3-VL-2B через OpenAI-совместимый сервер отвечает на вопросы; Florence-2-large создаёт описания и рамки. Совместно покрывают задачи описания и вопросов, но Florence сама не замена VQA. Сравнение качества и скорости с указанными вариантами не проводилось. |
| Tesseract rus или PaddleOCR | Другая конфигурация | PP-OCRv5 детектирует текст; GLM-OCR распознаёт документы; локальная PaddleOCR-VL опциональна. Восточнославянский распознаватель подключён к детектору для определения языка и выборки текста. Русский OCR требует отдельного теста; GLM-OCR не доказан лучше Tesseract. |
| CLIP ViT-B/32 | Замена | SigLIP2 для изображения и текста, дополнительно multilingual-e5 и BM25. Более широкий гибридный поиск и классификация типа/события — функциональные преимущества; превосходство качества поиска над CLIP на одной выборке не измерено. |
| `VisionModel.ask` и две реализации, lazy singleton, Depends | Выполнено | `vision.py` содержит `VisionModel.ask` и локальный/HTTP-адаптеры; `Depends` внедряет ленивый кэшируемый экземпляр. Веса локального адаптера загружаются при первом вызове. |
| Pillow размер/EXIF; ProcessPoolExecutor и очередь | Выполнено по механизму | `imaging.py`, `scanner.py`, `pipeline.py`: пул для импорта и подготовки; отдельная фоновая очередь обработки моделей. |
| SQLite + Parquet, эмбеддинги `.npy` | Выполнено | SQLite и BLOB остаются основной базой; пакетный маршрут экспортирует Parquet, массив эмбеддингов и соответствующие идентификаторы `.npy`. |
| FastAPI POST /describe, /ask, /batch; GET /search | Выполнено | Добавлены отдельные маршруты `/describe`, `/ask`, `/batch`, `GET /batch/{id}` и `GET /search`. Прежний API сохранён. |
| Gradio Blocks с вкладками | Выполнено | Добавлен опциональный Gradio Blocks с вкладками одной картинки, пакета, поиска и оценок; SPA сохранён. |
| CLI `vqa describe/ask` | Выполнено | Добавлены команды `vqa describe` и `vqa ask`, вызывающие работающий API. |
| Пакет 500 изображений с профилем узких мест | Выполнено с оговорками | Завершено 500/500 без ошибок, отдельно измерены декодирование, подготовка, модели, память и CPU. Первые 320 и оставшиеся 180 файлов обработаны разными режимами, сном системы и параллельной нагрузкой; см. `benchmarks/RESULTS.md`. |
| Flickr30k и invoices OCR | См. `benchmarks/README.md` и результаты запуска | Датасетные сценарии добавлены; малые выборки не доказывают качество всей системы. |

Результаты прогона 500 изображений и ограничения их сравнения приведены в `benchmarks/RESULTS.md`.
